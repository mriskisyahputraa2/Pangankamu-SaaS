# Development Scripts

This folder contains development and testing scripts that are not part of the main application.

## Files:

- `debug-supabase.js` - Script untuk testing unique constraint pada database
- `test-api.js` - Script manual testing untuk API endpoints

## Usage:

```bash
# Run debugging script
node scripts/debug-supabase.js

# Run API testing script
node scripts/test-api.js
```

## Note:

These scripts are for development/debugging purposes only and should not be deployed to production.
